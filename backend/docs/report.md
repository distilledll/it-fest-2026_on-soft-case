## Было → стало

Шаги: **baseline** — модель «как есть», один запрос со всей закупкой; **«не знаю»** — тот же запрос, но разрешены статусы «нет в документах»/«не знаю» (`direct`); **промпт** — постановка задачи агента (правила про изменения, расхождения, расчёты); **критики** — проверки кодом и повторы; **полный** — плюс критик-модель; **hybrid** — плюс резервный проход TrustQA, если агент сказал «не знаю». Если закупка не влезает в контекст модели, агент на всех шагах читает её фрагментами (узел `map`, map-reduce): всю, если фрагментов не больше 30, иначе — изменения извещения, лучший фрагмент каждого файла и остальные по поиску. Baseline — один запрос на каждый вопрос со всей закупкой.

## Проверки

| Проверка | Что ловит |
|---|---|
| `quote` | цитата дословно есть в документах (как в check.py); почти дословная подтягивается к точному тексту |
| `number` | каждое число ответа есть в цитате или рядом с ней; при нехватке код сам ищет подтверждение |
| `amendment` | значение не из старой редакции: разбор изменений извещения (в т.ч. «по номеру пункта», «утратил силу») |
| `conflict` | расхождение: значения одной части вопроса в разных файлах по evidence модели |
| `crosscheck` | сверка кодом без модели: тот же срок с другим числом в других файлах (веса по редкости слов) |
| `negation` | «требования нет»: «да»/число при цитате «не установлено»; «не требуется» без отрицания в цитате |
| `calc` | расчёт считает код: выражение calc, операнды из документов и не из старой редакции |
| `shape` | форма ответа: «сколько» → число, «до какой даты» → дата, «да или нет» → да/нет |
| `fields` | независимые извлекатели типовых полей (НМЦК, обеспечение, сроки, дата, гарантия) и правило «обеспечение = % × НМЦК» |
| `absent` | «нет в документах» проверяется: нет ли фразы про этот параметр с прямым отрицанием |
| `multipart` | вопрос из нескольких частей: разные части — не расхождение |
| `llm_critic` | вторая модель видит ответ, все цитаты и расчёт: соседний параметр, пропущенное отрицание |
| `guard` | финальный рубеж после любого пайплайна: цитата и числа, иначе «не знаю» |
